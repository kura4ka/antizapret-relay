# AntiZapret Relay

Модуль для [AntiZapret-VPN](https://github.com/GubernievS/AntiZapret-VPN): выбранные сайты открываются через другой ваш VPS вместо Cloudflare WARP.

Используется штатная маршрутизация AntiZapret в режиме **Custom**: домены задаются в `config/include-warp-hosts.txt`, исключения — в `config/exclude-warp-hosts.txt`. Модуль подключает ваш донорский VPS вместо Cloudflare; списки обрабатывает сам AntiZapret. Названия WARP в его настройках сохраняются.

**Донор** — VPS, через IP которого должны открываться сайты. **Клиент** — VPS с установленным AntiZapret, к которому подключаются ваши пользователи. Здесь клиентом называется сервер, а не телефон или компьютер.

Оба VPS могут находиться где угодно. Подсети, туннельные адреса и ключи создаются автоматически. На доноре AntiZapret необязателен; на клиенте он должен быть установлен и работать. Поддерживаются Debian/Ubuntu с systemd и WireGuard; целевые версии — Debian 13 и Ubuntu 24.04.

Все команды выполняйте по SSH **под root**. Если вошли другим пользователем, сначала выполните `sudo -i`.

## На доноре

### 1. Скачайте скрипт

```bash
curl -fSL https://raw.githubusercontent.com/kura4ka/antizapret-relay/main/install.sh -o install.sh
```

### 2. Запустите установку

Вместо `DONOR_IP` укажите **публичный IPv4 этого донорского VPS**:

```bash
bash install.sh server --endpoint DONOR_IP --port 51888
```

В панели хостинга откройте **UDP-порт 51888**. Если выбрали другой порт, укажите его и в команде, и в панели. На самом VPS правила firewall скрипт добавит автоматически.

### 3. Передайте настройки клиенту

Всё ещё **на доноре** выполните команду ниже. Вместо `CLIENT_IP` укажите **публичный IPv4 VPS с AntiZapret**, которому нужен этот донор:

```bash
scp /root/antizapret-relay-donor.json root@CLIENT_IP:/root/antizapret-relay-import.json
```

Если SSH запросит пароль — нужен пароль root **клиентского VPS**. Для нестандартного SSH-порта добавьте `-P НОМЕР_ПОРТА` после `scp`.

Файл содержит ключи подключения. Передавайте его через SSH и не публикуйте.

## На клиенте

Теперь подключитесь по SSH **к VPS с AntiZapret**.

### 1. Скачайте скрипт

```bash
curl -fSL https://raw.githubusercontent.com/kura4ka/antizapret-relay/main/install.sh -o install.sh
```

### 2. Подключите донора

```bash
bash install.sh client --bundle /root/antizapret-relay-import.json
```

IP, порт и ключи донора берутся из переданного файла — вводить их здесь не нужно. AntiZapret кратковременно перезапустится. Домены, которые уже были выбраны штатными списками WARP, начнут использовать донора.

### 3. Укажите домены в штатных списках AntiZapret

Всё выполняется **на клиентском VPS**. Откройте файл `/root/antizapret/config/include-warp-hosts.txt` в любом текстовом редакторе и добавьте нужные домены — по одному на строку:

```text
example.com
example.org
```

Если домен нужно исключить из маршрута через донора, добавьте его в `/root/antizapret/config/exclude-warp-hosts.txt`. Например, чтобы исключить один из поддоменов `example.com`:

```text
direct.example.com
```

Указывайте домены без `https://`, пути и `*`. Запись включает сам домен и его поддомены. Исключённые домены обрабатываются по остальным правилам AntiZapret.

После изменения любого из этих файлов примените списки **на клиентском VPS**:

```bash
/root/antizapret/parse.sh
```

В дальнейшем добавляйте и удаляйте домены в этих же файлах и снова запускайте `parse.sh`. На доноре списки доменов настраивать не нужно. Если видео, изображения или авторизация загружаются с других доменов, добавьте их отдельно.

**Учитываются все штатные списки WARP**, включая другие `config/*include-warp-hosts.txt` и списки из `download`. Исключения из `config/*exclude-warp-hosts.txt` продолжают действовать. Чтобы исключить домен, который присутствует в другом include-файле, внесите его в `exclude-warp-hosts.txt`.

### 4. Проверьте сайт

Переподключите VPN на телефоне или компьютере и откройте добавленный сайт. VPN-профиль менять не требуется. Если сайт продолжает использовать старый маршрут, очистите DNS-кеш устройства.

## Можно ли быть донором и клиентом одновременно?

Да. На одном VPS можно установить обе роли: отдавать свой IP другому серверу и отправлять свои выбранные домены через другого донора.

Для взаимного подключения двух VPS повторите разделы **«На доноре»** и **«На клиенте»**, поменяв VPS местами. Каждый раз в `DONOR_IP` указывайте IP того сервера, который сейчас настраиваете как донора. Файл собственного донора называется `antizapret-relay-donor.json`, полученный от другого — `antizapret-relay-import.json`.

Уже установленная роль сохраняется; сети выбираются автоматически. Поддерживается один донор для клиентской роли и один клиентский VPS для донорской роли. Один файл подключения нельзя раздавать нескольким VPS.

## Если не работает

На обоих VPS выполните:

```bash
antizapret-relay status
```

Сначала проверьте, правильно ли указан IP донора и открыт ли его UDP-порт. После открытия сайта с VPN-устройства в статусе туннеля должны появиться `latest handshake` и увеличиваться счётчики передачи.

Доменная маршрутизация требует DNS AntiZapret: сторонний DNS или браузерный DoH могут её обходить. Проверяйте сайт с подключённого VPN-устройства; запрос с самого VPS не проверяет этот маршрут. При недоступном доноре выбранные сайты не откроются — резервного выхода нет.

## Обновление

Выполните **на каждом VPS, где установлен модуль**:

```bash
curl -fSL https://raw.githubusercontent.com/kura4ka/antizapret-relay/main/install.sh -o install.sh
bash install.sh upgrade
```

Ключи и адреса сохраняются. Перед добавлением второй роли обновите старую установку этой командой.

## Удаление

На клиентском VPS — отключить использование донора и восстановить прежние параметры WARP:

```bash
antizapret-relay uninstall --role client
```

На донорском VPS — перестать отдавать свой IP клиенту:

```bash
antizapret-relay uninstall --role server
```

Если на VPS установлены обе роли, каждая удаляется отдельно. Для удаления обеих:

```bash
antizapret-relay uninstall --role all
```

## Дополнительная информация

- По умолчанию выбранные домены идут через донора и в профилях AntiZapret, и в профилях полного VPN. Для изменения только профилей AntiZapret добавьте `--antizapret-only` к команде установки клиента.
- DNS-настройки сохраняются. Донор заменяет выход WARP для трафика выбранных доменов; DNS продолжает работать по настройкам AntiZapret.
- При пересечении адресов с маршрутами клиентского VPS установщик остановится до изменения настроек. Работающий туннель автоматически не перенумеровывается.
- Ежедневные обновления AntiZapret сохраняют настройки. Перед полной переустановкой его `setup.sh` сохраните ключи и удалите клиентскую роль relay.
- Если после установки вручную менять управляемые параметры WARP, перед удалением потребуется согласовать их с резервной копией в `/etc/antizapret-relay`.

<summary>Дополнительные команды управления доменами</summary>

Команды из прежней инструкции продолжают работать **на клиентском VPS**:

```bash
antizapret-relay domain add example.org
antizapret-relay domain list
antizapret-relay domain remove example.org
```

Они управляют дополнительным файлом `config/relay-include-warp-hosts.txt`, который AntiZapret объединяет со штатными списками. Команда `domain list` показывает только этот дополнительный файл. Добавление и удаление применяются автоматически; штатные исключения действуют и для этих записей. Для обычного использования достаточно редактировать два штатных файла, указанных выше.
