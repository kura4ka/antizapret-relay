# AntiZapret Relay

**AntiZapret Relay** позволяет использовать собственный VPS вместо Cloudflare WARP для маршрутизации выбранных доменов. Трафик проходит через зашифрованный WireGuard-туннель на донорский сервер и выходит в интернет с его публичного IP.

Relay работает поверх штатной маршрутизации **AntiZapret в режиме Custom** и не заменяет сам AntiZapret.

Основные роли:

- **Server (донор)** — VPS, через который выходит выбранный трафик.
- **Client (клиент)** — VPS с AntiZapret, который отправляет выбранные домены через донора.
- **Both** — VPS одновременно работает как донор и как клиент другого донора.

Все команды ниже выполняются по SSH от имени `root`. Поддерживаются Debian/Ubuntu с systemd и WireGuard.

## Установка

Установщик один для всех ролей. Запустите его на каждом VPS отдельно:

```bash
curl -fSL https://raw.githubusercontent.com/kura4ka/antizapret-relay/main/install.sh -o install.sh
bash install.sh
```

В меню выберите нужную роль.

### Server — донор

Выберите `2 — Server / donor` на VPS, через который должен выходить трафик.

Укажите публичный IPv4 сервера и UDP-порт WireGuard (по умолчанию `51888`). Откройте этот UDP-порт в панели управления хостингом. Остальные параметры и ключи создаются автоматически.

### Client — клиент

Выберите `1 — Client` на VPS, где уже установлен AntiZapret.

Укажите публичный IPv4 донора и его SSH-порт (обычно `22`). Установщик подключится к донору по SSH и получит настройки WireGuard. Для этого нужен root-доступ по SSH.

Если SSH-доступа нет, файл подключения можно заранее передать на клиентский VPS вручную: `antizapret-relay-donor.json` с донора нужно скопировать как `/root/antizapret-relay-import.json`, а затем запустить установку командой:

```bash
bash install.sh client --bundle /root/antizapret-relay-import.json
```

### Both — обе роли

Выберите `3 — Both`, чтобы настроить на одном VPS и донора, и клиента. Сначала установщик настроит донорскую роль, затем предложит указать другого донора для клиентской роли. Если пока нужно настроить только Server, пропустите запрос IP второго донора нажатием Enter.

При установке Client или Both установщик также предложит добавить готовый список доменов Gemini. Его можно подключить сразу или добавить позже через команду управления.

## Управление

Все команды управления выполняются на соответствующем VPS.

### Статус

Посмотреть состояние Relay, роли и подключение WireGuard:

```bash
antizapret-relay status
```

### Домены

На клиентском VPS можно управлять дополнительным списком доменов командами:

```bash
antizapret-relay domain add example.org
antizapret-relay domain list
antizapret-relay domain remove example.org
```

Чтобы добавить готовый список Gemini или обновить его:

```bash
antizapret-relay preset gemini
```

Команды управления доменами работают с дополнительным файлом Relay:

```text
/root/antizapret/config/relay-include-warp-hosts.txt
```

**Можно редактировать списки и вручную**, без команд Relay. Основные файлы AntiZapret:

| Файл | Назначение |
|---|---|
| `/root/antizapret/config/include-warp-hosts.txt` | Домены, которые нужно направлять через донора |
| `/root/antizapret/config/exclude-warp-hosts.txt` | Домены, которые нужно исключить из этой маршрутизации |

Указывайте по одному домену на строку, без `https://`, путей и символов `*`. Запись распространяется на сам домен и его поддомены. Исключения имеют приоритет.

После ручного изменения файлов примените списки:

```bash
/root/antizapret/parse.sh
```

Домены настраиваются только на клиенте. На донорском VPS списки AntiZapret менять не нужно.

## Удаление

Роли можно удалять независимо друг от друга.

Удалить клиентскую роль:

```bash
antizapret-relay uninstall --role client
```

Удалить донорскую роль:

```bash
antizapret-relay uninstall --role server
```

Удалить обе роли:

```bash
antizapret-relay uninstall --role all
```

При удалении Client Relay восстановит прежние параметры маршрутизации. Автоматические исключения, добавленные Relay и не изменённые вручную, будут удалены. Пользовательские исключения сохранятся.

Домены, добавленные в основные списки AntiZapret, в том числе набор Gemini, автоматически не удаляются — при необходимости удалите их из файлов вручную.

## Обновление

Обновлять Relay нужно на каждом VPS, где он установлен.

```bash
curl -fSL https://raw.githubusercontent.com/kura4ka/antizapret-relay/main/install.sh -o install.sh
bash install.sh upgrade
```

Обновление сохраняет ключи, адреса и настройки ролей.

**Обновление самого AntiZapret — отдельная процедура.** Обычное обновление списков через `doall.sh` не требует удаления Relay. Перед полным обновлением AntiZapret с запуском upstream `setup.sh` сохраните конфигурацию Relay и WireGuard: установщик AntiZapret может изменить настройки WARP и WireGuard. После обновления проверьте состояние командой:

```bash
antizapret-relay status
```
